# QR Reader (Chrome extension)

Click the extension icon, drag a rectangle around a QR code on the page, and the decoded value is shown with a **Copy** button (plus **Open link** when it's a URL).

## Install

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** and pick this folder

Pin the extension to the toolbar for easy access. Shortcut: `Alt+Shift+Q`.

## Use

- Click the icon → drag a rectangle around the QR code
- `Esc` cancels; **Select again** lets you redraw
- Doesn't work on `chrome://` pages or the Chrome Web Store (Chrome blocks extensions there)

## Publish to the Chrome Web Store

1. Bump `version` in `manifest.json`
2. Build the upload zip: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1` → `dist/qr-reader-<version>.zip`
3. Fill in the dashboard using [store/STORE_LISTING.md](store/STORE_LISTING.md) (listing text, privacy answers, image list)
4. Host [store/PRIVACY.md](store/PRIVACY.md) publicly and paste its URL as the privacy policy

Screenshots come from `store/demo.html` (runs the real `content.js` with a stubbed screenshot call) and the promo tile from `store/promo.html`.

## Files

- `manifest.json` – MV3 manifest (`activeTab` + `scripting` only)
- `background.js` – injects the overlay and takes the screenshot of the visible tab
- `content.js` – selection overlay, cropping, decoding and result panel
- `icons/` – toolbar/store icons, generated by `tools/make-icons.ps1`
- `lib/jsQR.js` – [jsQR](https://github.com/cozmo/jsQR) 1.4.0 decoder
